# Kubernetes Labs

Hands-on Kubernetes labs, written up as I go.

I'm a Java backend engineer. I work with services running on Kubernetes
every day, and I wanted to understand the platform underneath them
instead of treating it as a black box. I passed the KCNA in September
2026 and I'm keeping the practice going, one lab at a time, towards
the CKA.

Every lab here is rebuilt from memory with imperative commands rather
than copied from a course. The point is the muscle memory, not the YAML.

## How each lab is written

- **The problem** — what it's about, in a line or two
- **What I did** — the actual commands
- **What I learned** — what surprised me, or what I got wrong first

## Environment

Local cluster (minikube / kind), `kubectl` from the terminal.
